### Products

- **[Alf](https://alfos.ai)**  
  Privacy-first AI assistant stack focused on self-hosting, control, and practical workflows for solo founders.

- **[ContactHive](https://apps.apple.com/us/app/contacthive-notes-contacts/id6738789375)**
